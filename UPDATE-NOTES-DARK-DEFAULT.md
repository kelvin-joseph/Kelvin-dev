# Dark default + preloader accent update

- Dark mode is now the default for first-time visitors.
- A visitor's explicit light/dark choice is still saved in localStorage.
- The site no longer uses the device colour-scheme as the first-visit default.
- Added a shared --logo-dot token tied to the site's accent colour.
- Preloader dot/accent selectors now use the same token as the logo dot, including dark mode.
