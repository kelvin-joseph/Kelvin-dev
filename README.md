# Kelvin — Portfolio (Competitive Visual Build)

A multi-page portfolio built around quiet confidence, warm editorial art direction and high-quality interaction.

- Warm ivory / charcoal / muted earthy palette
- Controlled typography scale
- Real project-first presentation
- MedTrack shown with selected public visuals only
- New replaceable profile photograph

## Interaction layer
- Page transitions
- Scroll progress
- Reveal animations
- Subtle parallax
- Magnetic buttons on desktop
- Custom cursor interaction on fine pointers
- Reduced-motion support

## Content
Profile, projects, services and contact options are content-driven through js/content.js and the existing local content mechanism.
